# 来路偕行与良辰入席改版开发方案

## 目标与边界

本次只规划，不修改 `src`、素材或构建产物。实施时在不改变既有页面路由、纸张视觉基调、分享能力和场地相册交互的前提下，完成以下两类改动：

- **来路偕行**：重写“同游、成长、奔赴、成婚”四段文案；六个故事阶段均提供左侧方形照片位，点击可放大查看，正文整体置于照片右侧。
- **良辰入席**：日程仅展示两字标题；调整相迎时间和到场提示，并在日程与场地之间加入邀请语。

`相恋`、`并肩`的现有文字与日期保持不变；它们仅随统一的照片位与放大查看能力调整布局。没有收到真实照片时，实施阶段保留明确的待替换方图占位素材，不虚构人物或场景照片。

## 目标文案

实施时将 `src/packages/story/data.ts` 中对应 `body` 更新为下列定稿；emoji 每段最多一个，作为情绪点缀而非正文主体。

| 阶段 | 文案 |
| --- | --- |
| 同游 | 在同一段山水里，我们慢慢学会彼此的步调；从你所见到我所感，零碎心意悄悄汇成相同的认知。🌿 |
| 成长 | 校园的岁月漫长而明亮。我望着你一步步走向钟爱的师范方向；你常捧一杯咖啡来实验室，陪我跑实验、写论文。我们把肆意的时间挥洒在并肩的日子里，也把冗长午后的阳光，珍藏成彼此的勇气。☕ |
| 奔赴 | 幸运的是，我们都在新的城市找到适合自己的工作，也从此把陌生的街巷点亮在共同的地图上。每一次出发，都是与生活温柔相认。🗺️ |
| 成婚 | 带着一路收集的回忆，也带着亲友盈满的祝福，我们将早已汇聚的爱意，翻开成新的篇章。 |

## 实施方案

### 1. 扩展故事阶段数据与素材约定

修改 `src/packages/story/data.ts`：

- 为每一个 `STORY_STEPS` 项补充 `photo`（本地分包路径）与具描述性的 `photoAlt` 字段，取消页面内“仅当索引为 1 时渲染照片”的硬编码。
- 继续使用现有 `story-trip.jpg` 作为“同游”临时或正式素材；为 `相恋`、`并肩`、`成长`、`奔赴`、`成婚`分别增加一张正方形或裁切安全的图片资源，统一置于 `src/packages/story/assets/`，并按阶段命名，例如 `story-growth.jpg`。
- 若真实照片尚未提供，创建与现有项目视觉一致、含“照片待补充”提示的方形占位图；后续仅替换同名文件即可，不影响数据、布局和交互。
- 将上表中的四段文案写入对应节点，日期和节点顺序不变。

### 2. 将故事时间线改为“左图右文”并实现图片放大

修改 `src/packages/story/pages/index/index.tsx` 与全局样式 `src/app.scss`：

- 每个时间线节点保留日期、红线和圆点；在节点内容区新增固定尺寸的左侧方形缩略图，右侧为标题及正文，确保所有正文相对当前版向右移动，且长文在窄屏正常换行。
- 将缩略图包裹为可访问的 `Action`，设置“查看{阶段}照片”的 `ariaLabel`。点击后打开故事专用预览弹层，展示当前阶段大图、阶段标题、日期与图片说明；支持点击遮罩和关闭按钮退出。弹层锁定底层 `Chapter` 滚动，关闭后恢复。
- 预览采用项目已有 `Photo` 组件的失败回退能力，并参照良辰入席的场地弹层使用固定层、遮罩、可滚动内容和安全区友好的最大高度；故事预览只需单图查看，无需上一张/下一张控件。
- 调整 `.story-list`、`.story-item`、`.story-date`、`.story-copy` 及新增 `.story-thumbnail`/`.story-dialog-*` 样式。缩略图保持 1:1、约 72–88px 视觉尺寸；正文列使用 `flex: 1; min-width: 0`，图片与正文间保持约 12px 间距。时间线圆点须仍与节点首行对齐，不能被图片遮挡。
- 保持既有纸张纹理、红棕色、边框和阴影语言；小图可采用浅色相纸边框，让六张图在时间线上形成一致节奏。

### 3. 精简良辰入席日程并更新提示文字

修改 `src/packages/day/data.ts`、`src/packages/day/pages/index/index.tsx` 及相关的 `src/app.scss`：

- 将第一项时间由 `11:00` 改为 `10:30`；四项的 `title` 均保留原有两字标题（相迎、入席、成礼、共宴）。
- 从 `SCHEDULE_ITEMS` 中删除 `note` 字段，并停止渲染日程项中的 `.body-copy`，使每个节点仅显示时间与两字标题。
- 在 `.schedule-list` 结束和 `.place-card` 开始之间插入独立的邀请语：`诚挚邀请您的出席`。使用现有 `subheading` 或新增轻量语义类，居中并留出与上下区域协调的呼吸空间。
- 将场地卡片到场提示替换为 `⌖ 建议在11:30前入场`，其余场地名称、照片数量、缩略图及场地相册弹层不变。
- 因日程说明移除而收紧每项垂直间距，保证邀请语、场地卡片和详情页页脚在常见窄屏中无需横向溢出，整体仍有舒展的留白。

### 4. 更新内容测试并完成验证

修改 `tests/content.test.ts`：

- 断言故事仍为六个节点，每项均具备照片路径与替代文字；校验四段更新后的文案（可使用精确字符串或关键语句），防止后续误回退。
- 断言日程仍为四项、首项时间为 `10:30`、所有标题均为两个汉字，且不再依赖 `note` 字段。
- 保留现有场地照片数量、目录标题与婚礼元数据断言；不为未提供的真实照片编造业务内容。

实施完成后依次执行：

```powershell
npm run typecheck
npm run lint
npm test
npm run check:assets
npm run build:weapp
npm run check:bundle
```

最后在微信开发者工具中人工检查：六个缩略图均为方形且文字在右、每张图可打开和关闭大图、长篇“成长”文案不截断、日程没有描述文字、“诚挚邀请您的出席”位于日程与场地之间、相迎为 10:30、到场提示为“建议在11:30前入场”。

## 影响文件清单

| 文件 | 改动性质 |
| --- | --- |
| `src/packages/story/data.ts` | 四段文案、六项照片元数据 |
| `src/packages/story/pages/index/index.tsx` | 左图右文渲染与单图放大状态/弹层 |
| `src/packages/story/assets/*` | 六个阶段的正方形可裁切图片或占位资源 |
| `src/packages/day/data.ts` | 日程时间与精简后的数据结构 |
| `src/packages/day/pages/index/index.tsx` | 移除日程描述、插入邀请语、修改入场提示 |
| `src/app.scss` | 故事时间线、故事弹层、精简日程与邀请语布局 |
| `tests/content.test.ts` | 更新后的内容与数据结构回归断言 |

## 不在本次范围

- 不更改婚期、场地名称、目录标题、页面导航或分享落地页。
- 不调整场地相册本身的图片、轮播逻辑或文案。
- 不实施真实照片的挑选、修图或人物图像生成；仅定义接口与占位替换方式。
