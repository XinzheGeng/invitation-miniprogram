# 发布清单

## 技术候选

- [ ] 将 `project.config.json` 的 `appid` 换为真实 AppID（不要提交 AppSecret）
- [ ] `npm ci && npm run verify` 全部通过
- [ ] 微信开发者工具导入项目根目录，基础库及包体检查通过
- [ ] iOS、Android 各至少一台真机完成六页导航、相册、弹层和分享检查
- [ ] 真实微信账号接收分享后从封面进入
- [ ] 320、375、390、430 等效宽度无裁字或横向溢出

## 内容与平台

- [ ] 替换或明确接受 17 个占位图片槽位，并重新检查包体及裁切
- [ ] 确认 `2017.xx` 是否作为正式故事日期
- [ ] 如需周边地点，提供人工核验的名称、地址和 GCJ-02 坐标
- [ ] 完成主体、名称、类目、认证、隐私配置及小程序备案
- [ ] 上传体验版、完成体验验收、提交代码审核；审核通过后另行发布

## 回退

保存发布提交、锁文件、压缩素材及上一可用版本。先核实微信后台是否支持目标版本回退；否则修复后重新提审。现有 Vercel 请柬继续作为后备入口。
